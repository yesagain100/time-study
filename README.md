# YesAgain — Time Study

Password-gated. Every process on the UAE refurbishment line with its time and its cost in AED,
built up from total overheads rather than a wage.

Live: https://yesagain100.github.io/time-study/

The page is encrypted (AES-GCM, PBKDF2-SHA256, 200k iterations) and decrypts in the browser only
when the team password is entered. Nothing readable is served without it.
